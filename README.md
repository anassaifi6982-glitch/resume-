# Mohd Anas — Data Science Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript. It is designed for free GitHub Pages hosting.

## Files
- `index.html` — page content and project cards
- `style.css` — dark navy/black theme, responsive layout, animations
- `script.js` — mobile menu, reveal animations, current year, back-to-top button

## Before publishing
1. Open `index.html` in a code editor.
2. Replace `https://github.com/` on each project card with the correct repository URL.
3. Replace the GitHub profile link, LinkedIn profile link, and `YOUR_EMAIL@example.com` with your actual details.
4. Add a resume PDF to the repository if you want a resume download link. Then add a link such as `<a href="resume.pdf" download>Download Resume</a>` where appropriate.
5. Check that every project description matches the current state of your code.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (replace `your-username` with your exact GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes and open `https://your-username.github.io/`.

If you use a different repository name, the site URL is usually `https://your-username.github.io/repository-name/`.

## Notes
- No backend or paid hosting is required.
- Google Fonts requires an internet connection; system fonts remain as a fallback.
- The `https://github.com/` links are placeholders. Update them before sharing your portfolio publicly.
